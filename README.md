# CleanWA

Projeto experimental de personalização visual para Android.

## Identidade visual provisória

O ícone provisório do CleanWA está em `assets/icons/` em resoluções Android mdpi, hdpi, xhdpi, xxhdpi e xxxhdpi, além da versão mestre de 512 px.

> Este repositório contém apenas identidade visual e materiais originais do projeto. Não distribui o APK, código proprietário ou recursos extraídos do WhatsApp.
